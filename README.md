# Personal Portfolio Website

A responsive personal portfolio website built using **Pure HTML, CSS, and JavaScript**. This project showcases skills, projects, experience, and contact information in a clean and modern user interface without relying on external frameworks.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and clean user interface
- Smooth scrolling navigation
- Contact form
- Animated elements using JavaScript
- Fast loading with no external frameworks

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
